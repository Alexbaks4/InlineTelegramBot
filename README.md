# 🚇 InlineTelegramBot — Сколько ехать до шараги (МИРЭА)

Инлайн Telegram-бот на C#, который по текущей геолокации пользователя определяет ближайшую станцию московского метро и рассчитывает примерное время в пути до кампуса РТУ МИРЭА на проспекте Вернадского, 78 (м. Юго-Западная).

## ✨ Возможности

* **Работа в любом чате (Inline-режим):** Бота не нужно добавлять в беседы — достаточно вызвать его через `@username_бота` прямо в строке ввода.
* **Автоматическая база станций:** При первом запуске бот автоматически скачивает актуальную схему московского метрополитена через публичный API HeadHunter (`https://api.hh.ru/metro/1`) и сохраняет её в локальную базу данных SQLite.
* **Визуализация веток:** Каждая линия метро и МЦД автоматически помечается соответствующим по цвету эмодзи (🔴, 🟢, 🔵, 🩵 и т.д.).
* **Умный расчёт локации:**
  * Если вы уже находитесь в радиусе кампуса МИРЭА (~500 метров), бот сразу напишет: *«Я в шараге»*.
  * Если вы находитесь близко к метро (до 2.5 км), бот покажет вашу станцию и время в пути.
  * Если вы далеко от метро (более 2.5 км), бот дополнительно укажет расстояние до ближайшей станции в километрах.
* **Защита от спойлеров:** Название станции, дистанция и итоговое время оборачиваются в HTML-тег `<tg-spoiler>`.

## 🛠 Технологический стек

* **Платформа:** .NET 10.0 / C#
* **Telegram API:** `Telegram.Bot`
* **База данных и ORM:** SQLite + `Microsoft.EntityFrameworkCore.Sqlite`
* **Парсинг данных:** `System.Text.Json`

## 📐 Как считается время и расстояние

1. **Евклидово расстояние с учётом широты Москвы:**
   Для быстрого поиска ближайшей станции используется приближённая формула перевода градусов широты и долготы в километры:
   ```text
   dist = sqrt(((lat1 - lat2) * 111.3)^2 + ((lon1 - lon2) * 62.5)^2)
   ```

2. **Расчёт времени до МИРЭА (`MinutesToMirea`):**
   Для каждой станции при инициализации БД рассчитывается расстояние до ст. м. «Юго-Западная» (`55.663146, 37.482852`), после чего применяется формула (в минутах):
   ```text
   T = max(1, round(dist * 1.95 + transfer + 9))
   ```
   Где:
   * `dist * 1.95` — примерное время движения поезда по прямой дистанции (в км);
   * `transfer` — `0` мин, если станция находится на Сокольнической (красной) ветке, иначе `5` мин на пересадку;
   * `9` — время пешком от метро «Юго-Западная» до главного входа в МИРЭА (в мин).

## ⚙️ Обязательная настройка в @BotFather

Поскольку бот использует геолокацию в инлайн-режиме и редактирует отправленное сообщение через `ChosenInlineResult`, перед запуском необходимо включить эти функции в [@BotFather](https://t.me/BotFather):

1. **Включите инлайн-режим:**
   Отправьте команду `/setinline`, выберите бота и укажите текст-подсказку (например, `Узнать время до шараги...`).

2. **Разрешите запрос геолокации в инлайне:**
   Отправьте команду `/setinlinegeo`, выберите бота и нажмите **Enable**. *(Без этого `Location` в запросе всегда будет `null`!)*.

3. **Включите отслеживание выбранных результатов:**
   Отправьте команду `/setinlinefeedback`, выберите бота и установите значение **100% (Enabled)**. *(Это необходимо для получения события `ChosenInlineResult` и `InlineMessageId`)*.

## 🚀 Запуск проекта

1. Склонируйте репозиторий и откройте проект в IDE (Visual Studio / JetBrains Rider).
2. Запустите проект.
3. При первом запуске программа создаст файл `token.txt` и попросит ввести API-токен вашего бота прямо в консоли.
4. После ввода токена бот автоматически скачает `metro.json`, сгенерирует базу данных `metro.db` и начнёт работу.

## 📂 Структура проекта

* `Program.cs` — точка входа, инициализация бота, чтение `token.txt`, скачивание JSON со станциями и первичное заполнение базы данных SQLite.
* `TelegramBotHandler.cs` — обработчик событий (`IUpdateHandler`). Отвечает за генерацию инлайн-ответа, обработку кнопки отмены и пересчёт координат пользователя в `SendTimeToMirea`.
* `MetroJson.cs` — модели данных (`MetroJson`, `Line`, `Station`, `LineData`) для десериализации ответа API и маппинга таблицы в Entity Framework.
* `MetroStationsDB.cs` — контекст базы данных `MetroStationsDBContext` (SQLite).
